# macOS 预发布版安装说明

本包为 PTA Code Typer v0.1.0 的公开测试包，仅包含 Apple Silicon（arm64）App。
在本机 macOS 26.6.2 + Edge 上测试通过；其他 macOS 版本、Intel Mac 和其他浏览器尚未验证。

## 安装位置

1. 解压 `PTA-Code-Typer-v0.1.0-macOS-arm64-prerelease.zip`。
2. 将解压后的整个文件夹移动到你的“个人文件夹”内，例如新建的 `Applications` 文件夹。
3. 从这个固定位置打开 `PTA Code Typer.app`。

本版采用便携式目录：App 会在自己旁边创建 `data/reports/` 保存代码备份和校验记录。
请保留所在文件夹的写权限，不要将它单独拖进系统 `/Applications`、放到只读磁盘，
或直接从压缩包预览运行。后续版本计划改用用户 Application Support 目录。
Python 与 Tk 已内置，无需安装 Python、pip、Homebrew 或浏览器扩展。

## 首次打开：开发者无法验证

本包仅使用 ad-hoc（临时）签名，没有付费 Apple Developer ID，也没有 Apple 公证。
这不妨碍通过 GitHub 分发，但首次下载打开可能被 macOS 拦截；本机测试并未模拟
从 GitHub 下载后带隔离标记的全新安装，也不保证受管理设备允许打开。

确认文件来自项目的官方 Release、校验值一致且你愿意信任此程序后：

1. 先尝试打开 App；如果系统拦截，关闭提醒。
2. 打开“系统设置 → 隐私与安全性”。
3. 在安全性区域找到该 App，点击“仍要打开”，再按系统提示确认。

“仍要打开”与下一节的“辅助功能”是两个独立步骤。系统没有该按钮或提示文件
已损坏、含恶意软件时，应先停止并反馈原始提示及系统版本。

Apple 官方说明：https://support.apple.com/zh-cn/102445

## 开启输入权限

1. 在 App 的“环境与权限”页点击“打开辅助功能设置”。
2. 在“系统设置 → 隐私与安全性 → 辅助功能”中开启 PTA Code Typer。
3. 没有该项时，点“＋”选择刚才固定位置中的 App。
4. 返回 App，点击“重新检测”。如仍显示未授权，退出并重新打开。
5. 首次识别浏览器时，macOS 可能询问是否允许控制 Edge 或 Chrome，用于读取标签页网址。

更新或自行重新构建后，如开关已打开却检测不到权限，可退出 App，移除旧授权项，
重新添加当前 App，再启动。临时签名可能随构建变化。

## 输入代码

1. 在浏览器打开 PTA 作答页面，切换英文输入法。
2. 在 App 中“读取剪贴板”或“导入文件”，核对预览。
3. 选择浏览器、速度、倒计时和校验方式。
4. 点击“开始输入”，倒计时内点击 PTA 可编辑的作答代码正文。
5. 等待完成。原内容先备份，再替换；App 仅输入和回读校验，不会提交答案。

F8（部分键盘需 Fn+F8）、鼠标移至屏幕左上角、切换其他应用或点击“停止”，均可中止。
中止后可能留下部分代码，请先检查。全文一致只表示输入正确，不保证解题或编译正确。

## 更新与反馈

本版没有自动更新。关闭旧 App，下载新版本并查看对应安装说明；如需保留备份，
自行保管旧 `data/`。反馈可在仓库 Issues 中填写系统、芯片、浏览器版本和复现步骤。
日志可能包含个人作答代码，不要直接公开整个 `data/` 文件夹。
