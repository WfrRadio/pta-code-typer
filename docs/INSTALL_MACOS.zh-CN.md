# macOS 原生版安装说明 · v0.2.0

需要 Apple Silicon Mac 和 macOS 26 或更新版本。已在 macOS 26.6.2 上构建和检查，未在 macOS 27 真机验证。

1. 解压 `PTA-Code-Typer-v0.2.0-macOS-arm64-prerelease.zip`。
2. 将 `PTA Code Typer.app` 放入固定位置，例如“应用程序”，再打开。
3. Python 输入组件已内置，无需安装 Python、Tk、Homebrew 或浏览器扩展。

## 第一次打开

本版使用 ad-hoc 临时签名，没有 Developer ID 签名和 Apple 公证。确认文件来自项目官方 Release 且校验值一致后，如系统拦截，可先尝试打开，再到“系统设置 → 隐私与安全性”点“仍要打开”，按系统提示确认。

Apple 官方说明：https://support.apple.com/zh-cn/102445

系统没有相应按钮、设备被组织管理或提示文件损坏时，请先停止并反馈原始提示。未在全新 Mac 上模拟 GitHub 下载后的隔离检查，不保证受管理设备允许运行。

## 辅助功能和浏览器授权

1. 在 App 侧栏选择“权限与环境”，点击“打开系统设置”。
2. 在“辅助功能”中启用 PTA Code Typer；没有该项时点“＋”选择当前 App。
3. 回到 App 重新检测；必要时退出再启动。
4. 首次控制 Safari、Edge 或 Chrome，系统可能询问自动化访问，用于读取标签页网址。

原生主程序与旧 Tk 版不同。更新后若开关已开启却仍显示未授权，请移除旧项并重新添加当前 App。只授权实际运行的那一份，不需要给 ZIP 或源码授权。

## 使用

读取剪贴板或导入 UTF-8 文件，核对预览，选择浏览器、速度、倒计时和校验方式。切换英文输入法，点击“开始输入”，在倒计时内点击 PTA 作答代码正文。完成后 App 返回显示结果，不提交答案。

F8 / Fn+F8、鼠标移至屏幕左上角或切换其他应用可停止。中止后代码框可能保留部分内容，请检查。

## 记录与更新

记录和备份在 `~/Library/Application Support/PTA Code Typer/reports/`，可从 App 的“运行记录”打开；无需给 App 安装目录写权限。旧版旁边的 `data/` 保留原状，不会自动迁移或删除。

当前没有自动更新，更新时退出旧 App 再替换。反馈可在仓库 Issues 中填写系统、芯片和浏览器版本；不要公开整个记录目录，以免包含个人代码。
